# Nikola Dimitrijevic – Portfolio Website

This repository contains the source code for my personal portfolio website. The site presents my background in software engineering and product development, highlights selected projects, and provides a clear overview of my experience, skills, and education.

## Overview

The portfolio is designed as a fast, responsive, and modern single-page website with a focus on clarity, usability, and professional presentation. It is deployed as a static site and requires no backend or database.

## Features

* Single-page layout with smooth scrolling navigation
* Responsive design optimized for desktop and mobile
* Project showcase with descriptions and links
* Experience, education, and skills sections
* Contact section with external links
* Performance-optimized animations and interactions

## Technology Stack

* HTML5
* Tailwind CSS
* JavaScript 

The site is built as a static frontend and is compatible with Vercel and other static hosting providers.



```bash
git clone https://github.com/DimePrangija/Portfolio.git
cd Portfolio
open index.html
```

Alternatively, you may run a simple local server if preferred.

## Deployment

The site is configured for static deployment and can be hosted on platforms such as Vercel, Netlify, or GitHub Pages without additional configuration.
